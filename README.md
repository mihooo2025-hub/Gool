# بوت نبض الملاعب - Goal.com Arabic

بوت آلي يجلب الأخبار من https://www.goal.com/ar فقط، يعيد صياغتها عبر Gemini AI
وفق قواعد صحفية محددة، ثم ينشرها كمسودة في ووردبريس مع تصنيف واختيار صورة بارزة،
ويرسل تقريراً إلى تيليجرام بعد كل دورة.

## هيكل المشروع

```
config.py            كل الإعدادات (تقرأ الأسرار من متغيرات البيئة فقط)
scraper_goal.py       جلب الأخبار الحديثة (آخر 3 ساعات) من Goal.com العربي
rewriter_gemini.py    إعادة الصياغة عبر Gemini (نموذجان + مفتاحان مع تبديل تلقائي)
rules_ar.md            قواعد الكتابة الصحفية الكاملة (يُقرأ كملف منفصل)
wordpress_client.py    رفع الصورة البارزة، مطابقة التصنيفات، إنشاء المسودة
telegram_notify.py     إرسال تقرير الدورة إلى تيليجرام
state_store.py         منع التكرار (رابط + تشابه عنوان) وقائمة إعادة المحاولة
main.py                 ينسّق كل الخطوات - نقطة التشغيل
.github/workflows/pipeline.yml   تشغيل تلقائي كل ساعة عبر GitHub Actions
data/state.json         سجل الأخبار المنشورة (يُحدَّث ويُحفظ تلقائياً بالمستودع)
```

## الإعداد (خطوة بخطوة)

### 1) إنشاء مستودع GitHub عام
ارفع هذه الملفات كما هي إلى مستودع جديد.

### 2) إنشاء Application Password في ووردبريس
من لوحة التحكم: المستخدمون → ملفك الشخصي → أسفل الصفحة "كلمات مرور التطبيقات"
أنشئ كلمة مرور جديدة واحتفظ بها (تُستخدم مرة واحدة فقط عند الإنشاء).

### 3) الحصول على مفتاحي Gemini API
من https://aistudio.google.com/apikey أنشئ مفتاحين منفصلين (حسابين مختلفين
يُفضّل، لضمان حصتين مجانيتين منفصلتين).

### 4) إنشاء بوت تيليجرام
تحدث مع @BotFather في تيليجرام لإنشاء بوت والحصول على التوكن،
ثم أضف البوت كمشرف في قناتك واحصل على chat_id الخاص بالقناة
(يمكن الحصول عليه عبر إعادة توجيه أي رسالة من القناة إلى @userinfobot).

### 5) إضافة الأسرار (Secrets) في المستودع
من إعدادات المستودع: Settings → Secrets and variables → Actions → New repository secret
أضف كل الأسرار التالية:

| اسم السر | القيمة |
|---|---|
| `GEMINI_API_KEY_1` | المفتاح الأساسي |
| `GEMINI_API_KEY_2` | المفتاح الاحتياطي |
| `WP_BASE_URL` | مثال: `https://nabdalmalaeb.com` (بدون / في النهاية) |
| `WP_USERNAME` | اسم مستخدم ووردبريس |
| `WP_APP_PASSWORD` | كلمة مرور التطبيق من الخطوة 2 |
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather |
| `TELEGRAM_CHAT_ID` | معرّف القناة |

### 6) التشغيل
الجدولة تعمل تلقائياً كل ساعة. يمكن أيضاً تشغيلها يدوياً فوراً من تبويب
Actions في GitHub → اختر "نبض الملاعب - Goal.com Bot" → Run workflow.

## القواعد الثابتة في الكود (كما طلبت بالضبط)

- المصدر الوحيد: `goal.com/ar` فقط.
- نافذة الفحص: آخر 3 ساعات، تُجلب كل الأخبار المتاحة ضمنها.
- لا صورة بارزة صالحة = تجاهل الخبر نهائياً (لا يُنشر أبداً).
- التصنيفات تُطابق فقط بالاسم الحرفي من قائمة ثابتة، ويُمنع إنشاء تصنيف جديد.
- تصنيف "Uncategorized" (الرئيسية) يُضاف إلزامياً مع كل خبر.
- تصنيفا "اهم الاخبار" و"مقالات وتحليلات" مستبعدان دائماً من اختيار الذكاء الاصطناعي.
- كل المقالات تُنشر بحالة "مسودة" فقط، أبداً لا تُنشر تلقائياً.
- 10 ثوانٍ بين كل عملية إعادة صياغة، و3 ثوانٍ بين كل عملية نشر.
- الأخبار التي تفشل معالجتها تُحفظ تلقائياً وتُعاد محاولتها في الدورة التالية،
  دون تكرارها إذا نجحت لاحقاً.
- منع التكرار عبر تجزئة الرابط بالإضافة لتشابه ضبابي للعناوين (عتبة 0.78).

## ملاحظة حول جلب الأخبار

الاعتماد الأساسي هو على قسم "أخبار عاجلة" في الصفحة الرئيسية وصفحة "آخر الأخبار"
في Goal.com، لأنه يعرض الوقت النسبي لكل خبر (قبل ساعة، قبل 3 ساعات...) مباشرة،
مما يسمح بتطبيق نافذة الثلاث ساعات دون الحاجة لفتح كل مقال لمعرفة تاريخه أولاً.

إذا غيّر الموقع تصميم هذا القسم مستقبلاً، قد تحتاج لتحديث دالة
`get_recent_article_links` في `scraper_goal.py`.
